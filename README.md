Entry for make.fun's **"The Moon Gets One Star"** bounty: the funniest one-star
review of the Moon in 120 characters or fewer. An AI judge picks the funnier
line pair by pair; the top review takes the $2 USDC reward.

## The review

> ★☆☆☆☆ Only works nights, changes shape weekly, and somehow the tides are still my problem. Would not orbit again.

113 characters. A rating, a grievance, and a reason the Moon earned its single
star — night shifts only, a new shape every week, and the tides are somehow
still our problem.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` (the file the scorer reads) and
prints exactly the same line to stdout, nothing else.
